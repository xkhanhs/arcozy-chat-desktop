# Arcozy Chat for desktop

Installers of the Arcozy Chat desktop app (macOS and Windows). The app is for Arcozy staff and asks for an Arcozy account.

Download the latest version from [Releases](../../releases/latest):

- macOS: `Arcozy-Chat-mac.dmg` (Apple silicon and Intel)
- Windows: `Arcozy-Chat-Setup.exe` (64-bit; Windows shows a SmartScreen warning once: "More info" → "Run anyway")

This repository holds the released files only.
